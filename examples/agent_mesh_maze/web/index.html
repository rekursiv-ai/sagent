Decentralized vs Centralized coordination

Same maze, same task: open every lock — each needs its two out-of-sight partners to press together, so they must communicate. The only difference between the two runs is the comms topology. Watch the mesh coordinate in parallel while the tree funnels everything through one coordinator.

MESH — any agent talks to any agent

TREE — workers talk only to the coordinator

Why the tree chokes and the mesh scales

Each lock is an independent coordination. The mesh handles all of them at once — every agent is in exactly one pair, so the work parallelizes (O(1) rounds). The tree puts a single coordinator on the critical path of every pair, so it serializes them (O(K)): it relays to one worker at a time, and as the number of locks grows it falls further behind. That is the whole story — no single sagent primitive is exotic; sagent just makes the mesh wiring as easy as the tree's, so the decentralized strategy is actually available.
