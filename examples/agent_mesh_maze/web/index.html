Why this needs sagent

Agents spawn agents and talk in every direction. Each maze runner is a persistent AgentSpawn peer with its own inbox; they coordinate with AgentSend — any-to-any, plus fan-out broadcast — and a routine message is read at the recipient's next decision while an urgent one preempts a move mid-step.

The wiring is the only difference. Both teams get the identical task and tools; the mesh lets discoveries reach everyone in one hop, while the tree funnels every update through one coordinator. The honest gap shows up under churn (and scale) — see the worklog.
